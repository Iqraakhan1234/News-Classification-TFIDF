# News Classification using TF-IDF

A machine learning project that classifies news articles using TF-IDF (Term Frequency-Inverse Document Frequency) and a machine learning classifier.

## Features

- Text preprocessing
- TF-IDF feature extraction
- News classification
- Machine learning based prediction
- Simple user interface

## Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- TF-IDF
- Machine Learning

## How to Run

1. Clone the repository.
2. Create a virtual environment.
3. Install the required dependencies.
4. Run the application.

```bash
pip install -r requirements.txt
python app.py
